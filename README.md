# 🌵 CactusCode

**Criatividade, tecnologia e a essência da Caatinga em um só lugar.**

## 📌 Sobre o projeto

O CactusCode é um projeto acadêmico que propõe uma fábrica de sites inspirada na Caatinga e no universo digital. A iniciativa busca unir identidade visual, criatividade e desenvolvimento web em uma proposta que valoriza elementos regionais e possibilidades tecnológicas.

## 🎯 Objetivo

Apresentar a identidade do CactusCode e sua proposta de criação de sites, explorando a integração entre design, tecnologia e referências à cultura e à natureza do Semiárido.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
